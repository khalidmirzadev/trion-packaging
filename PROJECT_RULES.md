# Trion Packaging Development Rules

## Tech Stack
- Next.js 15 App Router
- TypeScript
- Tailwind CSS v4
- shadcn/ui
- Framer Motion

## Design Style
- Premium
- Corporate
- Modern
- Apple-quality animations
- Clean whitespace
- Mobile-first

## Colors
Primary: #0F172A
Accent: #2563EB
Background: #FFFFFF
Secondary: #F8FAFC

## Components
- Reusable
- Server Components by default
- Client Components only when required
- Use shadcn/ui whenever possible

## Animations
- Framer Motion only
- Subtle animations
- No excessive effects
- 0.4s–0.8s duration

## Layout
- Max width 1280px
- Responsive
- Consistent spacing

## Code Quality
- Strict TypeScript
- No any types
- Clean folder structure
- SEO friendly
